# Deployment assets

Planned assets:

- Relay Dockerfile and single-node Compose example
- Caddy and Nginx TLS examples
- Connector launchd, systemd, and Windows service templates
- local development configuration with Fake providers
- release checksum, signature, and SBOM verification instructions

The OpenClaw Gateway is not deployed or exposed by these templates. It remains a
separately installed localhost service on the Connector computer.
